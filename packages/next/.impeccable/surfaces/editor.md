# Next.js content editor

Mode: Operate

Users browse collections, edit Markdown/MDX and frontmatter, save, upload images, and restore versions. This surface inherits the Astro editor's layout, controls, palette, typography, and themes. Platform branding reads Next.js; no new visual world is introduced.

Retain empty, loading, error, disabled, and saved states, keyboard navigation, search, history, and configuration access. Verify desktop and narrow layouts together. Authentication gates the entire editor in production. Host application styles must not enter this standalone editor document.
