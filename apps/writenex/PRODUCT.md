# Writenex

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People writing Markdown in a browser, with visual editing and portable exports.

## Product Purpose

Make writing and exporting Markdown straightforward and reliable. Protect the user's writing through local persistence, recovery drafts, and version history.

## Operating Context

The editor runs in the browser without an account. Documents stay in local browser storage. Offline use and workspace backups are core workflows. The separate Astro integration edits content collections.

## Capabilities and Constraints

Preserve visual, split, and source editing; multiple documents; Markdown and HTML exports; search and replace; version history; focus and read-only modes; keyboard shortcuts; and theme preferences. Browser storage is device-specific and can be cleared, so exports and backups must remain available.

## Brand Commitments

Preserve the existing Writenex identity. This maintenance task improves reliability and usability within the incumbent interface.

## Evidence on Hand

Implementation and feature documentation live in README.md and lib/. Existing screenshots are in public/screenshot-desktop.webp and public/screenshot-mobile.webp. Do not invent customer evidence or performance claims.

## Product Principles

- Protect writing before changing documents or restoring a workspace.
- Keep core editing available without accounts or connectivity.
- Make exports portable and recovery predictable.
- Preserve keyboard access and usability on narrow screens.
