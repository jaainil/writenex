# Design System: Writenex Configuration

## Overview

This directory contains the shared TypeScript configuration target in `typescript/`. It has no stylesheet, rendered interface, visual tokens, or component library.

Visual implementation belongs to [the web app](../../apps/writenex/DESIGN.md) and [the Astro editor](../astro/DESIGN.md). Refer to the consuming target’s document when working on UI. No visual seed or preview sidecar is generated for this nonvisual package.
